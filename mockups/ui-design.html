What is indirect prompt injection?
Indirect prompt injection is when an attacker plants malicious instructions somewhere the model will later read them — a web page, a PDF, an email, or a document in a RAG knowledge base 1. Unlike direct injection, the attacker never types into the chat themselves 1. RAG poisoning is a specific form of it, where the knowledge base is seeded with documents carrying hidden instructions 3.
